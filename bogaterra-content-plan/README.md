# Контент-план BOGATERRA — автономная версия артефакта

Автономная (один HTML-файл, без сборки) версия артефакта
[«Контент-план BOGATERRA»](https://claude.ai/artifact/MKtKYTu6mH7U9LQRbBCzi4):
сетка профиля, календарь на 6 недель, врачи, сторис и карусели К1–К8.

**Обновление 26.10.2026:** добавлено видео для первого Reels №1
«Анализы в норме, а сил нет?» (понедельник 26.10) — в сетку профиля,
в отдельный раздел-плеер и в календарь. Подробности и готовый промпт
для обновления исходного артефакта в Claude — в
[`REELS-01-VIDEO.md`](./REELS-01-VIDEO.md).

Видео не хранится в репозитории (57 МБ): страница встраивает его
плеером Google Диска по ссылке
https://drive.google.com/file/d/1RFrLeIWObXCtohaZdekqJGAwzyJ7cCtx/view?usp=sharing

## Просмотр

```bash
python3 -m http.server 8000 --bind 0.0.0.0 --directory bogaterra-content-plan
# открыть http://localhost:8000/
```

Фотографии клиники и врачей подгружаются с CDN исходного артефакта
(`*.frame.claudeusercontent.com`), постер видео — с Google Диска;
поэтому для картинок и плеера нужен интернет в браузере.
Если какое-то фото недоступно, ячейка мягко деградирует до брендовой
обложки с текстом (страница не «ломается»).
